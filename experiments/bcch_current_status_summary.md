## Core claim

Stable identity is not a fixed point.

Identity is a historically dependent trajectory kept inside an admissible region by an active boundary operator.

Canonical form:

```text
S_{t+1} = P_Omega(G(S_t, I_t))
```

where:

```text
G       = raw dynamics / model / environment update
P_Omega = boundary, projection or admissibility operator
Omega   = viable / admissible region
S_t     = system state at time t
I_t     = perturbation or input at time t
```

Short version:

```text
Identity is the admissible trace preserved through time.
```

---

## Key correction

The earlier contraction-first framing was too narrow.

Strict contraction can support homeostasis, recovery and reset, but it is not sufficient as a general model of identity.

Why:

```text
Contraction pulls trajectories toward the same attractor.
That can stabilize a system, but it can erase historical difference.
```

Revised view:

```text
Homeostasis = return toward stability.
Identity = historical continuity inside admissible boundaries.
```

Therefore, BCCH does not require global contraction. It requires an active boundary operator that can preserve viability and prevent unconstrained drift.

---

## Revised operator requirement

A valid `P_Omega` should be able to:

```text
1. distinguish admissible from non-admissible updates
2. block free propagation of harmful perturbations
3. return, clip or project the system back toward Omega when needed
4. preserve historical trace inside Omega
5. remain explicit enough to be tested or inspected
```

This means:

```text
k < 1 alone is not the essence.
Active boundary governance is the essence.
```
