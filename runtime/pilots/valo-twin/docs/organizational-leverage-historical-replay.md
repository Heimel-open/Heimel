# Observed Organizational Leverage Historical Replay v1

Status: proposed research/application delivery  
Issue: #36

## Question

The synthetic capability-on-demand model asks whether a small permanent organization can coordinate a much larger effective capability surface by acquiring bounded specialist competence only where it is needed.

This replay asks a harder question:

> What does actual VALO history currently prove about that thesis?

The answer is deliberately narrower than the synthetic result.

## Evidence discipline

Every measured field is classified as one of:

```text
OBSERVED
PRINCIPAL_ADJUDICATED
INFERRED
UNKNOWN
```

Only `OBSERVED` and `PRINCIPAL_ADJUDICATED` fields enter observed metrics.

`INFERRED` is preserved for analysis but is not counted as fact.

`UNKNOWN` must contain no numeric or boolean value. In particular:

```text
unknown discovery time != 0 hours
unknown sourcing latency != 0 hours
unknown internal capability != capability gap
unknown cost != 0 cost
actual principal contribution != principal irreducibility
no recorded external contributor != no external contribution
external framework/evidence contribution != observed human expert engagement
external contribution != execution authority
```

Inputs marked as available at the decision fail validation if their evidence timestamp is later than the decision timestamp. Post-hoc outcome/adjudication evidence is allowed for scoring but cannot be smuggled into the historical input state.

## Current observed result

The frozen v1 corpus contains five cases.

Observed/adjudicated fields establish:

```text
0 / 5  required capability profiles are independently observed/adjudicated as historical requirements
5 / 5  contain analytical capability labels inferred from source artifacts
3 / 5  contain recorded external capability contribution
3 / 5  are framework/evidence-provider contribution cases
0 / 5  are observed bounded human-domain-expert engagements
2 / 5  contain first-party material principal contribution
0 / 5  prove whether the required capability was unavailable internally
0 / 5  have observed discovery/context-transfer hours
0 / 5  have observed useful-judgement acquisition latency
0 / 5  have observed temporary-capability cost
0 / 5  have observed permanent-alternative cost
0 / 5  have principal-irreducibility adjudication
0 / 5  are complete enough for observed ROI calculation
```

That is the important result.

**The current historical record does not yet validate the human-expert elasticity thesis or support a real ROI number.**

The synthetic ROI model remains useful for scenario design and break-even analysis, but historical evidence cannot yet be promoted into observed organizational economics.

## What history *does* support

The current source corpus supports a narrower structural claim:

> VALO has repeatedly incorporated external framework/evidence capability while preserving its own state, contracts and execution-authority boundary.

The three recorded external episodes span materially different contribution classes:

```text
causal continuity / replay evidence
standing / admissibility framework
structured authority-state framework/evidence
```

All three preserve the same boundary:

```text
external capability may contribute evidence or judgement
                 !=
external capability owns execution authority
```

That structural modularity is compatible with the elastic-organization thesis. It does **not** yet demonstrate the specific commercial model in which a 5–10 person organization sources the right human specialist for one bounded decision and releases that capability afterwards.

## What must now be adjudicated or observed

For each historical case we need, where recoverable:

```text
1. What capability did the case actually require at the time?
2. Was that capability actually absent internally?
3. When did the gap become visible?
4. How much discovery/context transfer was required?
5. How long until useful judgement arrived?
6. Was the first routed person/capability correct?
7. Was rework required because of a wrong route?
8. Did the principal materially contribute?
9. Was that contribution genuinely irreducible for the decision?
10. What did the temporary capability actually cost?
11. What persistent staffing alternative would have been required and cost?
12. Were the two cost observations in the same currency/basis?
```

Fields that cannot be recovered stay `UNKNOWN`.

## Candidate routing boundary

The replay can emit a **counterfactual candidate route**, but only when the historical evidence is strong enough:

```text
known internal capability available
  -> INTERNAL

principal adjudicates judgement as irreducible
  -> PRINCIPAL_REQUIRED

known internal capability absent
+ known external capability contribution/candidate
  -> BOUNDED_EXTERNAL_CANDIDATE

otherwise
  -> UNKNOWN
```

The current five-case corpus therefore intentionally routes all five to `UNKNOWN`. This is not a failure of the thesis; it is a refusal to manufacture historical evidence that is not present.

## ROI completeness boundary

A case cannot be counted as ROI-complete merely because discovery and latency are known. The implementation requires grounded evidence for all of:

```text
required capability
internal capability availability
external contribution
context/discovery effort
useful-judgement latency
temporary capability cost
permanent staffing alternative cost
common cost currency
```

Only then may a later economics layer calculate an observed comparison. The v1 replay itself does not calculate enterprise ROI.

## Falsification rules

The implementation must fail or refuse scoring when:

- post-decision evidence is presented as if it were available at decision time;
- an `UNKNOWN` field carries a hidden value;
- an `INFERRED` field is counted as observed truth;
- principal adjudication is claimed without an explicit first-party adjudication reference;
- actual principal contribution is treated as proof of irreducibility;
- absence of a recorded contributor is turned into a false negative;
- framework/evidence contribution is silently counted as a human-domain-expert engagement;
- external competence is represented as granting execution authority;
- missing discovery, latency or cost is converted to zero.

## Architecture boundary

This module is research/application code in Valo-Twin.

It contains no `authorize` or `execute` primitive.

The only intended output is evidence-disciplined research about where organizational capability came from and what the historical record can or cannot support.
