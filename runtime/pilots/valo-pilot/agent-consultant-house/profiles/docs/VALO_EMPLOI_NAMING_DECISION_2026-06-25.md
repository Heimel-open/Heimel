# VALO Emplai naming decision

Date: 2026-06-25
Status: naming refinement

## Decision

Use `Emplai` as the public primitive name.

Keep `Employ` as the historical/internal ancestor term only.

## Why not Employ

`Employ` is too close to ordinary employment language.

It pulls the reader toward HR, labor law, jobs, employees and wage work.

That is not the core category.

VALO is not defining employment.

VALO is defining a verified working entity under identity, authority, delegation, budget, receipts and accountability.

## Why not Emploi

`Emploi` is elegant and close to the older semantic field.

But it is already the ordinary French word for job/employment.

It may still be useful as etymological support, but it is too crowded as the product primitive.

## Why not emPLoi

`emPLoi` is visually forced.

It looks like a brand trick, not an institutional primitive.

Avoid.

## Why not Emplay

`Emplay` sounds like play, gaming or engagement mechanics.

That weakens the seriousness of authority, budget, receipts and accountability.

Avoid.

## Why Emplai

`Emplai` keeps the root of employ/emploi.

It adds AI without spelling out AI too loudly.

It is short, pronounceable and ownable.

It separates the concept from ordinary employment while keeping the meaning:

```text
employ -> emploi -> emplai
work -> purpose -> AI-authorized work
```

## Definition

An Emplai is a verified working entity under delegated authority.

It can be:

- an AI agent
- a human-agent unit
- a team
- an organization
- another productive entity controlled by policy and receipts

For the current product boundary, only Agent Emplai is in scope.

## Grammar

Noun:

```text
Emplai
Agent Emplai
Verified Agent Emplai
```

Verb:

```text
to emplai
VALO emplaies an agent.
This agent has been emplaied.
Do not emplai an unverified agent.
```

Past tense:

```text
emplaied
```

Adjective:

```text
emplaied agent
emplaied workflow
emplaied authority
```

Avoid:

```text
employed agent
AI employee
synthetic employee
AI worker
```


## Moltbook wedge

The public challenge becomes:

```text
Any agent can act.
Few can prove they are an Emplai.

Prove identity.
Prove authority.
Prove delegation.
Prove budget.
Prove receipt.
```

Shorter campaign line:

```text
Do not just run an agent.
Emplai it.
```

## Migration rule

Existing docs may still contain `Employ`.

Do not mass-rewrite until the product language is stable.

Future docs should use `Emplai` for the primitive and mention `Employ` only as prior terminology.
