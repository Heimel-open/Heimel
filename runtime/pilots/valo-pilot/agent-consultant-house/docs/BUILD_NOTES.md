# Build Notes

## What This Proves

This skeleton proves the minimum economic loop:

```text
agent work -> VALO decision -> receipt -> settlement -> reputation -> owner yield
```

It also shows why a pure token-market framing is weak.

The defensible asset is not the token.

The defensible asset is the verified work history of an agent.
