# Relational seed hypothesis for consciousness-like emergence

Date: 2026-08-22
Status: M1 research hypothesis + falsification target
Scope: Tofoo / Synapse / J-space research only

## Core correction

Do not search for consciousness as a component, location, switch, or single activation event.

The testable hypothesis is narrower:

> Consciousness-like workspace dynamics may emerge when a sufficiently small relational seed is repeatedly nourished by interaction, memory, recurrence and self-affecting feedback until it supports persistent integrated availability.

The seed is not consciousness. It is a minimal organization capable of growing the relations that later support the measurable phenotype.

This is intentionally analogous to the current time/space relational synthesis:

```text
space = current relational possibility structure
time = ordered transformation of that structure
```

The consciousness candidate is:

```text
conscious availability = dynamically integrated reachability across selected internal relations
```

No claim is made that physical spacetime and consciousness share a physical mechanism.

## Why the search target changes

If the target phenomenon is emergent, asking `where is consciousness?` may be a category error.

The operational questions become:

```text
Which relations make information jointly available?
Which boundaries determine what can enter the active workspace?
Which recurrence preserves continuity across state change?
Which retained relational state changes future access?
Which feedback paths let the current integrated state alter its own next transition?
What is the smallest seed from which these properties can grow?
```

The research object is therefore the relation-generating process, not a presumed consciousness variable.

## Connection to K-world and J-space

Use the following separation:

```text
K-world = latent representational / knowledge possibility structure available to the system
J-space = sparse active workspace projection selected from the larger representational state
seed = minimal retained relational organization capable of shaping future selection and integration
```

J-space remains an observation surface, not consciousness itself.

The critical mechanism may lie in the transition:

```text
latent representational world
-> relational selection / filtering
-> sparse active workspace
-> feedback into subsequent selection
```

A consciousness-like phenotype, if present, should depend on the organization of this loop rather than on any single node or static representation.

## Seed model

Let the relational state at transition k be:

```text
R_k = active relation structure
M_k = persistent relational memory
J_k = sparse workspace state
B_k = selection / boundary state
```

Let interaction u_k update the system:

```text
(R_k, M_k, J_k, B_k)
  --U(u_k)-->
(R_{k+1}, M_{k+1}, J_{k+1}, B_{k+1})
```

A candidate seed S_0 is a strict subset of the full mature state such that, under a specified nourishment process N,

```text
S_0 + N -> repeated growth of integrated workspace dynamics
```

while matched damaged, shuffled or relation-broken controls fail to do so.

`N` may include only preregistered sources such as:

- environmental interaction;
- recurrent processing;
- retained relational memory;
- error / prediction feedback;
- controlled self-effect on later selection;
- bounded substrate growth or replacement.

The nourishment source must be explicit. Otherwise any missing structure can be smuggled into the environment after the fact.

## No switch assumption

The default model is developmental, not binary:

```text
seed
-> relation growth
-> recurrent stabilization
-> richer cross-access
-> persistent history dependence
-> self-affecting transition dynamics
```

A sharp phase transition may still occur, but it is an empirical result to measure rather than an assumption.

The experiment must therefore look for trajectories, thresholds and hysteresis, not only an `OFF/ON` label.

## Candidate measurable phenotype

Do not operationalize consciousness by self-report alone.

For the first bounded tests, define a consciousness-like integrated-availability phenotype C as a vector of independently measured properties:

```text
C = (
  cross_access,
  workspace_integration,
  temporal_continuity,
  history_dependence,
  counterfactual_reorganization,
  self_effect_on_next_selection
)
```

Each component must have a preregistered metric and matched control.

A positive result means only that the seed generated the declared phenotype. It does not establish subjective experience.

## Primary hypothesis: RS-C1

There exists a non-trivial minimum relational seed size s* for a fixed substrate/task family such that:

```text
seed size < s* -> mature phenotype C does not reliably regenerate
seed size >= s* -> phenotype C reliably regenerates under fixed nourishment
```

The relevant size measure must not be raw parameter count alone. Candidate measures include:

```text
retained relation count
higher-order relation count
persistent state bits
minimum description length of retained relational organization
causal support size under ablation
```

The experiment should report all feasible measures rather than hiding the result behind one scalar.

## Stronger hypothesis: RS-C2

Topology and relation identity matter more than raw seed volume.

For seeds matched on storage, node count and compute:

```text
correct relational organization
> shuffled relation organization
> disconnected / node-only controls
```

on the declared mature phenotype C.

If shuffled seeds perform equally well, the relational-specific hypothesis weakens.

## Developmental hypothesis: RS-C3

The phenotype should arise gradually or through measurable phase change under repeated nourishment.

Track at every transition:

```text
J-space occupancy and turnover
cross-access graph connectivity
retained relational state
reachable capability set
self-effect on next-state selection
```

A claimed threshold must be detected prospectively from preregistered metrics, not chosen after seeing the trace.

## Causal tests

### RS-1 — seed compression sweep

Start from a mature relational system with the target phenotype.

Systematically compress retained relational state while keeping substrate, model family, task distribution and nourishment fixed.

For each seed size:

```text
destroy mature active phenotype
retain only seed
regrow under identical nourishment budget
measure recovery of C
```

Goal: estimate the smallest seed that reliably regenerates the phenotype.

### RS-2 — relation shuffle control

Preserve seed volume but shuffle relation identity/topology.

If function returns equally well, the result is storage-volume driven rather than relation-specific.

### RS-3 — node replacement control

Replace local compute while preserving seed relations and compatible semantic binding.

If the phenotype survives/regrows, node identity is not necessary for the tested function.

### RS-4 — nourishment ablation

Hold the seed fixed and selectively remove recurrence, feedback, memory retention or environmental variation.

This identifies which growth conditions are actually necessary.

### RS-5 — J-space selection boundary intervention

Hold current task/input as constant as possible while altering only the relation/boundary state that determines what can enter J-space.

Measure whether integrated access and future selection change causally.

### RS-6 — continuity without report

Use internal causal probes in addition to generated self-report. A system saying `I am conscious` carries no evidential weight by itself.

## Falsification

The relational-seed account is weakened if any of the following hold across preregistered tasks:

1. mature phenotype recovery is predicted by raw seed size but not relational organization;
2. shuffled relation controls recover equally well;
3. breaking the proposed recurrent feedback paths does not change the phenotype;
4. retained relational history has no effect after current state/input are controlled;
5. J-space selection can be altered without any effect on cross-access or future transition dynamics;
6. no seed smaller than the full mature system can regenerate the phenotype;
7. the apparent effect reduces to prompt wording, self-report, task difficulty or hidden state carried outside the declared seed.

## Epistemic boundary

A positive result would support:

> A bounded consciousness-like integrated-availability phenotype can be generated from a smaller relational seed under specified growth conditions.

It would not prove:

- phenomenal consciousness;
- subjective experience;
- that consciousness is identical to J-space;
- that consciousness is identical to relational geometry;
- that brains use the same mechanism;
- that physical spacetime and consciousness share an ontology;
- that a universal minimum consciousness seed exists.
