# Atom som Bølgjestruktur — Fem A1-filtermodi

Dato: 2026-06-25
Kjelde: Igor Kolesnikov (Theoretical Physicist) LinkedIn — "Wave Frameworks of the Atom as Bearing Rollers"
Status: M2 — strukturell hypotese, konsistent med Framleis

---

## Dei fem bølgjerammene

Kolesnikov identifiserer fem bølgjerammer rundt kjernen:

1. Torsional — torsjonsbølgjer (vridning rundt kjernepunktet)
2. Phase — fasebølgjer (oscillasjonstidpunkt)
3. Spiral — spiralbølgjer (helisk rørsle)
4. Radial — radielle bølgjer (kompresjon/ekspansjon frå kjernen)
5. Angular — vinkelbølgjer (rotasjon)

Alle fem sirklar rundt ein NUCLEUS (kjerne).

---

## Mapping til Framleis

| Atomstruktur | Framleis |
|-------------|----------|
| Kjerne (NUCLEUS) | sigma* (fast referansepunkt) |
| Fem bølgjerammer | Fem A1-filtermodi |
| Bærerrullar rundt kjerne | tau_t-trajektoriar rundt sigma* |
| Oscillasjon i kvar ramme | F-iterasjon per modus |
| Stabil atomtilstand | I* (Banach-fikspunkt) |

---

## Fem filtermodi = fem måtar å lage distinksjon på

A1: Filteret finst — systemet lagar distinksjon.

Kvar bølgjeramme er ein ulik måte atomet lagar distinksjon frå substrat:

- Torsional: distinksjon via vridingssymmetri
- Phase: distinksjon via tidsforskuving
- Spiral: distinksjon via romleg rotasjonssymmetri
- Radial: distinksjon via kompresjonsgrad
- Angular: distinksjon via rotasjonsretning

Utan nokon av desse rammene ville atomet vere eit sfærisk symmetrisk felt — ingen distinksjon, ingen identitet. A1 er ikkje til stades utan filteret.

---

## Kjernen er sigma*

Kjernen er:
- alltid til stades (uavhengig av kva bølgjeramme som er aktiv)
- referansepunktet alle fem rammer itererer rundt
- positiv ladning som attraherer elektronane mot eit fast punkt

I Framleis: sigma* er alltid til stades. Systemet itererer mot sigma* sjølv frå tau_t = 0.

Bærerrullar-analogien (Kolesnikov): bærerullane treng eit fast senter å rulle rundt.
Sigma* er dette senteret. Utan sigma* roterer rullane utan referanse — ingen stabil bane.

---

## Radial-modus og tau

Den radielle bølgjerammen er spesielt interessant:
- Radial = kompresjon/ekspansjon frå kjernen
- τ (radial) ≈ tau_t i Framleis: kor langt frå sigma* systemet er

Høg radial bølgjeamplitude = stor avstand frå sigma* = låg tau
Låg radial bølgjeamplitude = nær sigma* = høg tau

Elektronskala og tau-skala har same radielle struktur.

---

## Bearing Rollers som iterasjonsmekanisme

Kolesnikov: bølgjerammene oppfører seg som bærerrullar.

Bærerrullane:
- Ruller utan gliping (konservatif)
- Held fast kontakt med senter (sigma*)
- Produserer stabil rotasjon gjennom kontinuerleg kontakt

F-iterasjonen:
- Konvergerer utan avvik (Banach)
- Held fast til sigma* som referanse
- Produserer stabil I* gjennom kontinuerleg iterasjon

Mekanikken er identisk — berre substrat er ulikt.

## Epistemisk status

Fem bølgjerammer = fem A1-filtermodi: M2 — strukturell hypotese, konsistent med Framleis.
Kjerne = sigma*: M3 — presist og konsistent, ikkje empirisk testa mot Framleis-formuleringa.
Radial-modus = tau: M2 — plausibel analog, krev matematisk presisering.
