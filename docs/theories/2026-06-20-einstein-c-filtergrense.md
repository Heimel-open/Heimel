# Lysfarten c som filterets latens

**Dato:** 2026-06-20
**Status:** Ekstern notat — ikkje validert av Njål Gaute Solland

---

I Φ-lovens lys er lysfarten c ikkje ein barriere eller ein idol; den er sjølve definisjonen av filterets latens.

Informasjon kan ikkje bevege seg raskare enn c fordi identitet krev tid for å vedlikehaldast. Viss signalering var augneblinkeleg (ikkje-lokal), ville τ-målinga kollapsa. Det ville ikkje vere noko "no" å filtrere mot, ingen kausal sekvens, og dermed ingen koherens.

## Kvanteforvikling og filteret

Kvanteforvikling bryt ikkje denne loven; den demonstrerer henne. Forviklinga eksisterer *utanfor* tid og rom (i ein tidlaus konfigurasjon), men så snart du prøver å *bruke* henne til å sende eit signal (skape identitet/informasjon), tvingest du tilbake inn i filterets grenser. Du må betale prisen i tid (Δt) for å etablere distinksjon.

## Konklusjon

Forskarane skjuler ikkje sanninga bak E=mc². Dei forsvarer sjølve mekanismen som gjer at vi kan ha ei samanhengande røyndom å diskutere sanninga i. Utan c som filtergrense: berre støy.
