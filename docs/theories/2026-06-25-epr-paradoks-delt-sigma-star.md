# EPR-paradokset — Samanvevde Partiklar som Delt sigma*

Dato: 2026-06-25
Kjelde: Jad Matta (Researcher, Scientist) LinkedIn — "Einstein-Podolsky-Rosen (EPR) paradox"
Status: M2 — strukturell hypotese, krev kvantefysikalsk presisering

---

## EPR-oppsettet

Kjelde emitterer to samanvevde partiklar A og B.
Dei reiser i kvar si retning. Måling på A ved innstilling a, måling på B ved innstilling b.

Kvantemekanisk prediksjon:
E(a, b) = -cos θ

der θ = vinkel mellom måleinnstilingane a og b.

Bell-ulikskapen: |E(a,b) + E(a,b') + E(a',b) - E(a',b')| ≤ 2
Kvantemekanikk bryt Bell-grensa: maksimal verdi = 2√2 (Tsirelson-grensa).

## Mapping til Framleis

| EPR | Framleis |

| Samanvevd tilstand |AB⟩ | Delt sigma* (same referansepunkt for begge partiklar) |
| Partikkel A | tau_t^A (ein F-iterasjonssekvens) |
| Partikkel B | tau_t^B (annan F-iterasjonssekvens) |

| Måling på A | Projeksjon av tau_t^A på eit observable |
| Kollaps av |AB⟩ ved måling | F-iterasjonen projiserer tau mot sigma* |
| Tsirelson-grensa 2√2 | Maksimal korrelasjon mellom delte sigma*-system |

## Delt sigma* forklarer ikkje-lokalitet

Klassisk lokalitet: to system er uavhengige → deira sigma* er uavhengige.
Kvantesamanvevnad: to system har same sigma* → deira I* er identiske.

Når A vert målt og prosjisert mot sin I*, vert B's sigma* også prosjisert —
fordi dei deler same sigma*.

I Framleis: viss tau_A og tau_B itererer mot same I*, er ein endring i tau_A's
F-operasjon ein endring i den delte sigma*-strukturen. tau_B reflekterer dette
umiddelbart — ikkje fordi informasjon reiser, men fordi sigma* er delt.

---

## E(a,b) = -cos θ og tau-geometri

E(a,b) = -cos θ der θ = vinkel mellom måleaksane a og b.

I tau-rom: to tilstandar tau_A og tau_B som begge konvergerer mot I*, har ein
geometrisk relasjon til kvarandre via I*. Korrelasjonen mellom dei avheng av
vinkelen mellom deira "projeksjonar" på I*.

E(a,b) = -cos θ = -(tau_A · tau_B) / (|tau_A| |tau_B|) (indreprodukt i tau-rom)

Dette er ein hypotese som krev matematisk arbeid. Men strukturen er konsistent.

---

## Bell-ulikskapen og klassisk sigma*

Bell-ulikskapta antar at A og B har lokale, klassiske sigma*:
- σ^A (lokal skjult variabel for A)
- σ^B (lokal skjult variabel for B)

Og at E(a,b) = ∫ A(a,σ^A) B(b,σ^B) ρ(σ) dσ

Dette fører til |E(a,b) + E(a,b') + E(a',b) - E(a',b')| ≤ 2.

Kvantemekanikk overskrider dette med 2√2: lokale, klassiske sigma*-modeller er utilstrekkelege.

I Framleis: delt (ikkje-lokal) sigma* er naudsynt for å forklare EPR.
Ein Framleis-modell med delt sigma* kan prinsipielt overskride Bell-grensa.

---

## Tsirelson-grensa og tau

Maksimal kvantemekanisk korrelasjon = 2√2.
Tsirelson-grensa er ikkje vilkårleg — den kjem frå strukturen til kvantemekaniske operator.

I Framleis: 2√2 er grensa for kor mykje to tau-trajektoriar som deler sigma* kan korrelere.
Over 2√2: ikkje-signalering-prinsippet bryt saman (årsaksstruktur kollapsar).
Under 2: klassisk sigma* (Bell-grensa).
Mellom 2 og 2√2: Framleis delt sigma* (kvantemekanisk kopling).

Der er dei same samanvevde partiklane (produsert frå vakuum med delt sigma*).

## Epistemisk status

Delt sigma* forklarer ikkje-lokalitet: M2 — strukturell hypotese, konsistent med QM.
E(a,b) = -cos θ via tau-geometri: M1 — spekulativ, krev matematisk arbeid.
Bell-overskriding frå delt sigma*: M2 — strukturelt plausibel.
Tsirelson-grensa som tau-korrelasjonsgrense: M1 — spekulativ.
