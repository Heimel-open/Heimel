## Source scope

Healey argues that organizations are measuring agentic AI like a software rollout instead of measuring business outcomes. Adoption, usage and sentiment may show activity, but they do not establish financial value.

Her proposed frame is operational and CFO-facing:

- define one measurable outcome per agent;
- define a unit of work that can be priced and compared;
- include the full operating cost, not only token spend;
- treat evals, monitoring, permissions, audit trails, escalation and human review as part of the business case rather than compliance overhead;
- establish a human-only baseline before deployment;
- measure foundation conditions such as data quality, governance maturity, integration depth, workflow readiness and ownership clarity;
- retire generic adoption and "hours saved" metrics when they cannot be tied to revenue, margin, cost, risk or cash flow.

The post cites external survey figures from PwC and other sources. Those figures are secondary claims in this note and should be verified against their primary sources before being used as quantitative evidence in VALO publications.

## External signal

The important signal is not a new governance architecture. It is a change in how governance is economically framed.

The conventional framing is:

`governance -> compliance cost / friction`

Healey's framing is closer to:

`governance -> ability to scale safely -> measurable business outcome`

That is strategically important because it places governance inside the value equation rather than outside it.

A system that cannot be measured, owned, controlled and stopped cannot produce defensible ROI at scale, even if its model-level performance is strong.

## VALO interpretation

This source is external validation for a distinction already central to Handlingsrett.

Governance can define:

`purpose -> ownership -> controls -> measurement -> accountability`

But consequential agentic execution still requires an additional runtime question:

`May this concrete action execute now?`

That requires current authority, admissibility, purpose, constraints, evidence and state to be checked at the execution boundary.

Mapped to the current VALO execution chain:

`governed state -> VAIG -> reht -> RACS -> enforcement -> Veritas evidence`

Healey's framework therefore supports the economic case for governance without replacing the execution-governance architecture.

The source stops at a harness/governance layer. It does not specify fresh authority at commit time, deterministic action clearance, revocation-sensitive execution authorization, a single governed effect path, or cryptographically bindable execution evidence.

## GTM implication

The CFO case for Handlingsrett should not be presented primarily as "another safety layer."

It can be expressed as infrastructure for converting agent activity into controlled, measurable economic outcomes.

A useful commercial chain is:

`baseline -> proposed action -> current authorization -> governed execution -> observed outcome -> evidence -> unit economics`

This makes it possible to ask not only whether an agent was used, but:

- what unit of work it performed;
- whether the action was valid at execution time;
- what the governed action cost;
- whether it reduced rework, exception handling or failure recovery;
- whether it improved cycle time without increasing unauthorized-action risk;
- whether the claimed value can be demonstrated afterwards.

## Candidate VALO economics metrics

These are VALO-derived metrics, not metrics proposed by Healey.

### Outcome metrics

- cost per valid completed action;
- cycle time per valid completed action;
- revenue or margin contribution per governed workflow;
- risk-adjusted value per executed action;
- successful-outcome rate after authorization.

### Governance efficiency metrics

- invalid or stale-authority actions prevented before effect;
- rework avoided by pre-execution rejection;
- exception-handling cost per workflow;
- human step-up rate by risk class;
- mean time to resolve authorization failure;
- audit reconstruction time per action;
- percentage of consequential actions with complete evidence chains.

### Scale metrics

- governed actions per human supervisor;
- governed actions per unit of control-plane cost;
- percentage of workflows that can move from manual approval to bounded autonomy without increasing residual risk;
- time from pilot to controlled production;
- marginal governance cost per additional agent or workflow.

## Research hypothesis

A stronger economic hypothesis follows from the source:

`Agentic ROI is not model ROI.`

For consequential workflows, realized value depends on the entire execution system:

`model capability × workflow fit × authority validity × control quality × integration quality × outcome capture`

If any required factor approaches zero, useful economic value can collapse even when model capability remains high.

This gives VALO a falsifiable research direction: compare nominal agent productivity with governed realized value under shadow, approval, bounded and continuous execution modes.

## Strategic classification

Treat this source as:

- external validation that governance is becoming part of the AI business case rather than a separate compliance budget;
- support for outcome-based rather than adoption-based agent measurement;
- support for explicit ownership, baseline measurement and full-cost accounting;
- support for pricing governance/harness costs into agent unit economics;
- a CFO/COO positioning signal for Handlingsrett;
- a bridge between execution governance, Veritas evidence and demonstrable ROI;
- not evidence for changing VALO architecture.
