The governed path

Agents may plan freely. Consequences require authority.

Heimel sits below models, agents and orchestration. It does not decide what an agent should think. It decides whether the exact proposed effect is authorized now.

Designed for trust

The boundary is the product.

Not another agent platform. A narrow, independently testable infrastructure layer for systems that can create real effects.

Fresh authority

Past approval cannot silently survive revocation, expiry or changed conditions.

Exact binding

A permit applies only to the state, action and effect that were authorized.

Fail closed

Missing authority, mappings or evidence never degrade into permission.

One-shot permits

Execution authority is not a reusable bearer token. Replay is rejected.

No direct effect path

Consequential actions pass through the boundary or they do not happen.

Verifiable evidence

The system records the operative decision, execution and observed effect.

When humans can no longer keep a finger on every button, authority, limits and responsibility must follow the button itself.
