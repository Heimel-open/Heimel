Open Heimel · local installation

Run the governed consequence path yourself.

Open Heimel is independently runnable. No account, phone-home connection or license server is required for local authorization, enforcement, replay and evidence.

Requirements

Python 3.11 or newer

Use an isolated virtual environment.

Git

Clone the public repository at the exact commit you intend to evaluate.

Local test environment

Do not point first runs at real consequence-bearing production systems.

Clone

git clone https://github.com/Heimel-open/Heimel.git
cd Heimel

Create an environment

python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip

Install the reference packages

python -m pip install -e "packages/kernel[dev]"
python -m pip install -e packages/runtime

Run the local consequence-path tests

python -m pytest runtime/runtime-local/tests -q

Verify the release

python3 tools/release_verify.py
The contract SDK demonstration does not claim to execute the complete governed consequence path. Use the local runtime tests when evaluating the full boundary.
