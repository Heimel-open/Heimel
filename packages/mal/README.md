# VALO MAL reference slice

This package is the first selective extraction from the private
`valo-platform` repository. It contains only the deterministic policy
federation reference surface.

The package can decide whether a signed policy pack is admissible for local
review. It does not activate a model, grant execution authority, access
credentials, or connect to a production control plane.

The source provenance and boundary are recorded in `repo-manifest.yaml`.
This package is a reference contract, not a publication of `valo-platform` or
the OLAV application/runtime.
