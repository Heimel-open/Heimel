# Scripts (Research-fabrikkens motorer)

Disse scriptene ble brukt til å generere rapporten. De kan regenerere alt fra rådata.

## Kobling til fabrikk

Rådata + data-pipeline bor i `~/agentic-execution-risk/data/` og `~/agentic-execution-risk/research/`.
Her (Valo-Research-Group) er bare **generator-scriptene** — de kan brukes til å:

1. Regenerere rapporter (`generate_report.py`)
2. Produsere professional PDF (`build_professional_report.py`)
3. Lage visualiseringer (`gen_charts.py`, `gen_charts_rest.py`)
4. Modell-rapportering (`model_report.py`)

## Kjør
```bash
cd ~/agentic-execution-risk/
python research/generate_report.py
```
