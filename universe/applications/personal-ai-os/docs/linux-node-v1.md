Delivery target: an installable local relAIon node for Linux.

Ownership boundary:

- relAIon Core owns identity, lineage, canonical memory and relational developmental state.
- REHT remains the sole admissibility authority for effects; absence of REHT fails closed.
- Models, harnesses, MCP servers, surfaces and other capabilities are subordinate, replaceable providers.
- No provider may silently redefine the primary objective or acquire canonical identity, memory or execution authority.
- Surface adapters are transport only and do not become relAIon.

Initial deployment shape:

`surface -> local relAIon core -> capability provider -> governed proposal -> REHT -> effect/receipt`

State is local and persistent. Cloud capability is optional for continuity and identity.
