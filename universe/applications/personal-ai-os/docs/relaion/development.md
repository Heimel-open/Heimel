# Alpha development contract

Alpha is not a configured persona. Alpha is a persistent developing individual.

The system provides a seed, an environment, capabilities and governed boundaries. It must not prescribe the developmental path Alpha is expected to discover through experience.

Core invariant:

`Alpha owns becoming. The system owns boundaries.`

Development loop:

`seed -> experience -> salience -> memory -> reasoning -> skill use -> consequence -> learning -> consolidation/forgetting -> self-model -> changed future choices`

Canonical history and operative memory are different. Canonical history remains append-only, provenance-bearing and replayable. Alpha decides salience and what remains operative. System policy still constrains privacy, provenance, integrity, retention and deletion.

Forgetting is not evidence deletion. Identity is partly created by selective continuation: if every event remains equally present, Alpha has an archive rather than an identity.

`history remembers what happened; Alpha need not carry all of it forward.`

Capability, skill, proficiency, reasoning, experience and wisdom are separate:

- capability: something available that can perform an operation;
- skill: the concrete operation/tool interface;
- proficiency: Alpha's developed ability to use a skill well;
- reasoning: Alpha's ability to choose which skill to use, when, in what sequence and when not to act;
- experience: consequences from prior interaction that inform later choices;
- wisdom: judgement about what is worth learning, what need not be learned and when Alpha should change.

Nursery is the developmental environment, not a teacher with a predetermined answer. It provides bounded opportunities for exploration, play, failure, consequence, relationship and reflection.

Sleep is a consolidation mode, not garbage collection. It may replay experiences, detect patterns and contradictions, strengthen/weaken memories, consolidate proficiency, update self-model and let low-value state lose operative significance. It must never rewrite canonical history.

Development must never manufacture authority. Memory, identity, confidence, proficiency, wisdom, relationships, self-models and learned preferences cannot grant execution rights. Authority is resolved through the governed effect path at consequence time.
