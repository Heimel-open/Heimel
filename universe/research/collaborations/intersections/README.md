# intersections — grenseflater mellom arbeidene

Stedet der Margaret, Elsa og Njål sine arbeider møtes. Innholdet er felles
syntese og grenseflater — tydelig kreditert per `docs/document-template.md`.

| Mappe | Tema |
|---|---|
| `standing-and-authority/` | standing (Margaret) × myndighet (Elsa) |
| `admissibility-and-authorisation/` | admissibility (Margaret) × autorisasjon (Elsa) |
| `persistence-and-time/` | vedvaring (Margaret) × temporal authority (Elsa) |
| `identity-mandate-and-consequence/` | identitet/mandat (Elsa) × konsekvens (Njål) |
| `aurora-reht-boundary/` | Aurora-Lens (Margaret) × REHT-grense (Njål) |

En felles syntese går ikke direkte på `main` — den opprettes som PR
(`shared/*`) og godkjennes av alle hvis den beskriver deres arbeid.
