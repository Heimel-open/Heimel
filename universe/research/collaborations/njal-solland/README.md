# njal-solland — Njål sitt forskningsspor

Originalt arbeid eid av **Njål Gaute Solland**. Dette sporet er koblet til
VALO-repoene (Tofoo-, synapse-lab, valo-*, reht) — referanser hit er
forskningsinput, ikke autoritet.

| Mappe | Tema |
|---|---|
| `tofoo/` | Tofoo / Φ-loven, måleplass for planthelse-claims |
| `j-space/` | J-space, iterativ stabilisering |
| `framleis/` | framleis, lokal-til-global teori om adaptiv identitet |
| `operational-fixed-points/` | operasjonelle fikspunkter |
| `execution-governance/` | utførelsesstyring og REHT-grenser |

Den røde tråden: **hva kan stabiliseres, autoriseres og faktisk få
konsekvens?**
