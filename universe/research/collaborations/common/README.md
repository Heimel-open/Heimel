# common — felles forskningsflate

Spørsmål dere undersøker sammen, felles terminologi, prinsipper og
krediterte synteser. Originalt arbeid ligger i hver persons egen mappe.

| Mappe | Innhold |
|---|---|
| `research-principles/` | felles forskningsprinsipper og kvalitetskrav |
| `shared-questions/` | spørsmål som undersøkes sammen |
| `terminology/` | felles begrepsdefinisjoner |
| `synthesis/` | krediterte felles synteser |
| `decision-log/` | logg over felles beslutninger (peker til `adr/`) |

Regler:

- Ingen omskriving av andres arbeid uten synlig diff og godkjenning.
- Hver syntese er tydelig kreditert (`docs/document-template.md`).
- Felles konklusjoner besluttes i `adr/` med navngitte godkjennere.
