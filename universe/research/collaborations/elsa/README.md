# elsa — Elsa sitt forskningsspor

Originalt arbeid eid av **Elsa**. Ingen endrer dette sporet uten synlig
diff og Elsa sin godkjenning.

| Mappe | Tema |
|---|---|
| `authority-instrumentation/` | hvordan myndighet instrumenteres |
| `mandate-and-scope/` | mandat og omfang |
| `temporal-authority/` | tidsavgrenset myndighet |
| `revocation/` | tilbakekalling av myndighet |
| `human-authority/` | menneskelig autoritet |

Den røde tråden: **hvem har myndighet, innenfor hvilket mandat, tidsrom
og omfang?**
