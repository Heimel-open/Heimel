## Scout frontier A — minimal sufficient cognitive coalition

Source claim: `C-BSE-002`.

### DERIVATION

The source already implies:

1. full-ensemble deliberation is not the default objective;
2. coalition choice is conditioned by required risk coverage, latency/compute cost and human-attention cost;
3. disagreement is evidence, not a vote;
4. consequential/value/authority-sensitive cases may require principal or governance involvement regardless of model confidence.

A direct operational consequence is that the system should stop adding reasoners when required coverage is satisfied and no material unresolved issue remains. This is derivation, not a new primitive.

### SYNAPSE candidate — Residual-Driven Coalition Expansion

Candidate mechanism:

```text
start with smallest plausible specialist set
  -> produce candidate + explicit residual
  -> residual = missing evidence / unresolved contradiction /
                uncovered consequence domain / uncertainty /
                authority or value ambiguity
  -> add only the specialist best matched to a material residual
  -> repeat
  -> stop when no material residual remains and mandatory coverage is satisfied
```

Candidate new research object: `COGNITIVE_RESIDUAL`.

A cognitive residual is not disagreement count or confidence. It is the decision-relevant uncertainty left unexplained after the current coalition has worked.

Possible next-specialist selector:

```text
next_projection = argmax_p expected_residual_reduction(p) / marginal_cost(p)
```

subject to mandatory risk/human/governance coverage.

Why this may matter: it turns coalition selection from a static "pick N agents" problem into sequential information acquisition. A swarm expands only when the current work exposes a reason to expand.

Epistemic status: `SPECULATIVE / candidate mechanism`.

### FALSIFIER

Matched task families:

- fixed full ensemble;
- residual-driven expansion;
- single general model baseline.

Fail the candidate if residual-driven expansion materially reduces compute/attention but repeatedly misses a critical constraint, contradiction or consequence that the fixed full ensemble catches.

A particularly strong counterexample is a high-impact task where the first specialist reports low residual but an excluded specialist discovers a decisive hard constraint. That would show that self-reported residual is insufficient as the expansion signal.

### Immediate practical implication

The earlier 400-run Synapse matrix is the opposite of the source hypothesis: it maximizes deliberation before demonstrating that the extra deliberation is useful. A resource-safe swarm should expand conditionally rather than pre-allocate the whole coalition.

## Scout frontier B — trustworthy representation continuity

Source claims: `C-LIM-001`, `C-DDNA-001`, `C-FRL-001`.

### DERIVATION

The source already supports a narrower operational object than personal identity:

```text
representation continuity
!= personal identity
!= predictability
```

Continuity can be evaluated using provenance, lineage, declared invariants, amendment basis, contradiction state and integrity across a representation transition. A surprising change may still be legitimate when that lineage remains intact.

`C-LIM-001` as personal/ontological identity remains under-specified and not falsifiable as stated; the existing falsification backlog explicitly requires an operational restatement.

### SYNAPSE candidate — Continuity Challenge Set

Candidate mechanism:

Add a versioned set of decision-relevant counterfactual probes to the representation continuity contract.

```text
R0 + challenge_set_v0
  -> transformation / new evidence / amendment
  -> R1
  -> replay continuity challenges
  -> compare which relational commitments changed
  -> require provenance/amendment basis for material change
```

The challenge set would not require identical answers across time. Instead it records which response relations are expected to remain invariant unless an evidenced amendment explains the change.

Candidate new research object: `CONTINUITY_CHALLENGE_SET`.

Purpose: detect semantic drift that can preserve hashes, provenance and formally declared structural invariants while silently changing decision-relevant meaning.

This is not proof of personal identity and does not create authority.

Epistemic status: `SPECULATIVE / candidate mechanism`.

### FALSIFIER

Construct adversarial representation updates that:

- preserve source provenance;
- preserve recorded lineage;
- satisfy all currently declared invariants;
- but flip a decision-relevant preference, commitment or interpretation without an amendment basis.

If ordinary Framleis checks accept the transition and the proposed challenge set also consistently misses the semantic drift, the mechanism adds little value.

Conversely, legitimate novelty must be allowed: if new evidence justifies changed challenge responses and the mechanism rejects that change merely because it is surprising, it has collapsed continuity back into predictability and fails.

## BRIDGE candidate — cognitive residual × continuity challenge

The two frontiers may share a deeper pattern:

> Do not allocate more cognition or preserve more state merely because more is available; preserve/expand only what is decision-relevant and expose the unresolved remainder explicitly.

Potential bridge:

- `COGNITIVE_RESIDUAL` says what remains unresolved in reasoning;
- `CONTINUITY_CHALLENGE_SET` says what must be checked when represented understanding changes;
- accepted frontier updates can carry both the resolved delta and the remaining residual forward in lineage.

This could make the Frontier Garden itself cumulative without becoming a forced-closure machine.

Epistemic status: `SPECULATIVE_BRIDGE`.

## Scout result

Strongest immediately useful candidate: **Residual-Driven Coalition Expansion**.

Reason: it directly converts the existing Tofoo principle "smallest sufficient cognitive coalition" into a resource-aware exploration mechanism and addresses the exact failure mode observed when a fixed 400-run matrix was prepared before signal existed.

Second candidate worth preserving: **Continuity Challenge Set** as a possible semantic-drift test for Framleis representation continuity.

No result is accepted into `CLAIM_REGISTRY.md` by this run. Both remain Garden candidates pending further challenge or experiment.
