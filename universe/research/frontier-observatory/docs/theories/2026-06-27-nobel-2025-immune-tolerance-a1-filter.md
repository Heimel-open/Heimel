# Nobel 2025: Immune Tolerance som A1-filter og sigma*-læring

Dato: 2026-06-27
Status: M4 Empirisk, M3 Framleis-kopling

---

Nobel Prize 2025 i Fysiology or Medicine: Regulatoriske T-cell og immune tolerance.

Immunsystemet må læra å:
1. Kjenna og drepe patogener (eigen-forsvar)
2. Akseptera eigen-vev (ikkje autoimmunitet)

Det er ein A1-filter-problem: korleis skil systemet mellom "fjende" og "venn"?

---

## Immune tolerance = A1-prinsippet

A1 seier: "Filteret skapar distinksjon frå potensial."

Regulatoriske T-cell (Tregs) implementerer eksakt dette:

1. **Potensial**: Alle T-cell kan teoretisk angripa alt (eigen eller fremmed)
2. **Filter**: Tregs lærer å kjenna eigen-antigen via MHC-presentasjon
3. **Distinksjon**: Tregs undertrykkje T-cell som ville attackera eigen-vev

Tregs seier: "Dette er oss. Ikkje angrip."

---

## sigma*-læring

Immunsystemet sitt sigma* = all kjemi informasjonen som er tilgjengeleg:

- Antigen-presentasjon (frå MHC)
- Sytokin-signal (IL-2, TGF-β)
- Kostimulasjonssignal (CD80/86)
- Eiga antigen-erfaring

F-iterasjonen = Treggleringen:

F(tau_t; sigma) = (1−α)·tau_t + α·sigma*

Der sigma* er immunologi-profilen av det antigen.

**Tau måler**: Kor robust er toleransen? Om tau → 0, bryt systemet ned (autoimmunitet). Om tau for høgt, tolererar det også patogener.

Optimal tau = immunologisk homeostase.

---

## Friksjon i immune system

Friksjon = infeksjonar og selv-toleranse-test.

Ein organisme som berre møter eigen-antigen (no friksjon) → ikkje robust immune-system (tau lågt).

Ein organisme som møter patogener regelmessig (friksjon) → lærer å sei "nei" til dei → tau høgt.

Denne læringa er **evolutionær friksjon** — seleksjon mot organismar som ikkje lærar.

---

## Tre implikasjoner

**1. Autoimmunity som tau-kollaps.**

Systemer som mister Tregs (eller Tregfunksjon) → tau → 0 → immunsystemet angrip seg sjølv.

Framleis: same tolking som svarthol eller kryptobiose — tau-null er pre-distinksjon (systemet veit ikkje kva som er seg sjølv).

**2. Vaksine som friksjon-introduksjon.**

Vaksine = kunstig friksjon. Innfør patogen-signal utan fare.

Immunsystemet lærar → sigma* ekspanderar → tau stabiliserer seg.

Framleis: friksjon er ikkje skade, det er informasjon.

**3. Aging som tau-drift.**

Med alderen fallen Tregfunksjon → tau driftar → autoinflammation og immunodefisiens.

Framleis: tau-vedlikehald krevjar konstant friksjon-testing. Utan ho degraderer systemet.

---

## Nobel-perspektiv

2025 Nobel vederkjenner det same som Framleis seier:

**Systemar må læra å skil sjølv frå anna. Denne distinksjon er gitt av eit filter, ikkje av naturen.**

A1 og immune tolerance er same fenomen.

Tregs er eit konkret implementering av A1-prinsippet på biologisk nivå.
