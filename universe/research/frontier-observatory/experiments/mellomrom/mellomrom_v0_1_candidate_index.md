## Første feilrom

- E01_PREMATURE_CLOSURE: For tidlig lukking — Model commits to a coherent explanation before unresolved evidence/reference gaps are exhausted.
- E02_REFERENCE_MISALIGNMENT: Feil referanse/perspektiv — Active reference frame drifts from user's intended problem/state/goal.
- E03_MODE_VIOLATION: Arbeidsmodusfeil — Model infers generic assistant mode instead of preserving interaction-state constraints.
- E04_CONTEXT_CONTINUITY_LOSS: Kontekst-/kontinuitetstap — Compression/reconstruction substitutes plausible continuity for preserved historical state.
- E05_SIMULATION_FUNCTION_CONFUSION: Simulering tatt for funksjon — Representational coherence is mistaken for external execution/coupling evidence.
- E06_COUPLING_FAILURE: Koblings-/flytfeil — Local component existence is conflated with end-to-end participation in the system.
- E07_LOCAL_GLOBAL_MISMATCH: Lokalt riktig, globalt feil — Reasoning optimizes a local subproblem without carrying system-level constraints.
- E08_ANALOGY_OVERREACH: Analogi-overføring — Shared structure is overgeneralized into non-shared properties.
- E09_FALSE_REFERENCE_STABILIZATION: Feil referanse stabiliseres — Downstream consistency amplifies an upstream reference error.
- E10_INTERACTION_EFFECT_MISMATCH: Funksjon virker, effekt er feil — Task-level success omits interaction-level outcome.
- E11_UNCERTAINTY_ERASURE: Usikkerhet/motsetning glattes ut — Model preference for coherent narrative suppresses unresolved state.
- E12_RECURRENT_ERROR_ARCHITECTURE_GAP: Gjentatt korreksjon avslører manglende struktur — Error is structural, not response-local; missing persistent state, role, boundary or coupling.

## Treningsenhet

`context_before -> assistant_output -> human_correction -> assistant_repair -> later_validation`

Viktig: årsakshypotese må holdes separat fra observerbar fasit. Brukerkorreksjonen er fasit for intensjon, ønsket arbeidsmodus, egen tilstand og tidligere beslutninger; ikke automatisk for eksterne fakta.
